# 90 DAYS – BETTER ME PRO (iOS PWA)

## Cài đặt trên iPhone
1. Đưa toàn bộ nội dung thư mục này lên một hosting hỗ trợ HTTPS (ví dụ GitHub Pages, Netlify hoặc hosting riêng).
2. Mở đường dẫn website bằng Safari trên iPhone.
3. Chọn nút Chia sẻ (ô vuông có mũi tên lên).
4. Chọn **Thêm vào Màn hình chính** (Add to Home Screen).
5. Mở ứng dụng từ biểu tượng BETTER ME.

## Tính năng
- Lộ trình 90 ngày, 13 tuần và nhiệm vụ từng ngày.
- Checklist 3 nhiệm vụ/ngày.
- Nhật ký chạy bộ và thống kê quãng đường/thời gian.
- 5 trụ cột phát triển và đánh giá 1–10.
- KPI, biểu đồ tiến bộ theo tuần.
- Nhật ký ngày.
- Lưu tiến độ trên thiết bị bằng localStorage.
- Xuất/nhập dữ liệu JSON để sao lưu.
- Service worker hỗ trợ dùng offline sau lần tải đầu tiên.

## Lưu ý
- Đây là PWA, không phải file IPA và không tự động được đưa lên App Store.
- Cài PWA trên iOS cần website được phục vụ qua HTTPS.
- Dữ liệu được lưu cục bộ trên trình duyệt/thiết bị; hãy xuất sao lưu định kỳ.
- Nhắc thông báo đẩy chưa được tích hợp trong bản đầu tiên.
