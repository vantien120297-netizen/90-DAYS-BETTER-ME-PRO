## V2.0
- Lộ trình 90 ngày và checklist 3 việc/ngày.
- Nhật ký chạy bộ/đi bộ, KPI, đánh giá 5 lĩnh vực.
- Tổng kết tuần trong 13 tuần.
- Cài giờ nhắc và xin quyền thông báo.
- Xuất/nhập JSON để sao lưu.
- Lưu dữ liệu cục bộ trên thiết bị.
