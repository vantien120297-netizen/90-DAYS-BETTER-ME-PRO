# 90 DAYS – BETTER ME PRO V2.1

PWA tiếng Việt, giao diện Dark Mode đen-vàng.

## Nâng cấp V2.1
- Giữ các tính năng V2.0: lộ trình 90 ngày, checklist, nhật ký vận động, KPI, nhật ký cá nhân, tổng kết tuần, nhắc nhở, sao lưu/khôi phục JSON.
- Biểu đồ hoàn thành nhiệm vụ theo 13 tuần.
- Lịch 90 ngày dạng heatmap để nhìn nhanh mức độ duy trì.
- In hoặc lưu báo cáo tiến độ 90 ngày dưới dạng PDF qua hộp thoại in của trình duyệt.

## Cập nhật GitHub
Tải lên và ghi đè 5 tệp tại thư mục gốc repository, commit vào `main`, chờ GitHub Pages triển khai rồi tải lại website.

Lưu ý: dữ liệu vẫn lưu cục bộ trên thiết bị, chưa có đồng bộ đám mây. Thông báo trình duyệt không đảm bảo chạy nền khi ứng dụng đã đóng. Hãy sao lưu JSON định kỳ.
